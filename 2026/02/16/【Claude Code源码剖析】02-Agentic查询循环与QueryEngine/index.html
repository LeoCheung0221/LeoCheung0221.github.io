十一、Generator 模式的优势

query() 使用 async function* (异步 Generator) 的设计是关键：

为什么不用回调/EventEmitter？

  • Generator 保持了 顺序控制流，代码可读性好
  • 调用方可以 暂停/恢复 消费（背压控制）
  • 与 React 的渲染周期完美配合
  • 错误可以通过 try/catch 正常捕获（不像 EventEmitter）
